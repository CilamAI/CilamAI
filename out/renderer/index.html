v0.1.0.1

August 14, 2026

Improvements & Bug Fixes

  • Fixed Cloud Model Routing: Corrected an issue where Gemini and Grok models were incorrectly routed through the default proxy, causing "Invalid token" errors. They now route securely to their native OpenAI-compatible endpoints or your custom proxy.
  • API Key UI Enhancement: Added a visual reference screenshot and a complete "How to get your API Keys" guide directly in the settings panel with handy links to all developer consoles.
  • Cleanups: Fully deprecated and removed legacy Z.ai configuration.

v0.1.0

August 12, 2026

New Features

  • Initial release of CilamAI desktop chat application
  • Real-time streaming responses for instant feedback
  • Multi-language support: English, Korean, Turkish, Russian
  • File upload functionality for document sharing in chat
  • Screenshot capture tool integrated into chat
  • Session search and history management
  • Model selection and switching between available models
  • Credit/usage tracking with 24-hour reset cycle
  • Notification system with error, warning, and info states
  • Help menu with keyboard shortcuts and links
  • GitHub integration for repository access

Customization

  • Multiple theme options: Dark, Light, System, Blue, Red, Yellow, Green, Black
  • Adjustable chat text size (Small, Default, Large, Extra Large)
  • Customizable hotkeys with reset to defaults option
  • Launch on startup option

Core Features

  • Real-time chat with streaming responses
  • Message history with search functionality
  • Model selection and switching
  • Credit/usage tracking and context window management
  • Help menu with keyboard shortcuts and links
  • GitHub integration for repository access

Bug Fixes & Improvements

  • Optimized performance for smooth chat experience
  • Improved markdown rendering for better readability
  • Enhanced input history navigation
  • Stable window management (minimize, maximize, restore)
