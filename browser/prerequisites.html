Prerequisites

System requirements and dependencies for running CilamAI Desktop.

Operating System

Windows 10 64-bit or Windows 11 recommended.

Node.js Environment

Node.js v20.0.0 or higher (for building from source or running developer mode).

node -v

Git Command Line

Git installed and configured in your PATH environment variable.

git --version
