mimo-v2.5

MiMo V2.5 is an advanced AI coding & reasoning model fine-tuned for high efficiency and fast local inference. Run it entirely offline on your computer with CilamAI.

Install

$ npm install

Run

$ npm start

Features

  • Open-source and free
  • Runs fully offline
  • 128K context window
  • 14B parameters
